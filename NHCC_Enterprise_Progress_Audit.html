Phase 0 — Prisma ORM Migration 100%

Migrated the entire data layer from raw sql.js (SQLite in WASM with handwritten SQL strings) to Prisma ORM with a fully typed 22-model schema.

How to see this on the frontend

  • Every page that loads data (Projects, Tasks, Messages, etc.) is now powered by Prisma queries instead of raw SQL
  • Data loads faster with proper pagination and indexed queries
  • The app will feel the same to the user — but the backend is now enterprise-grade

Phase 2 — Concurrent Data Protection 100%

Prevents data loss when two people edit the same record simultaneously. Also prevents duplicate form submissions.

How to see this on the frontend

Test scenario: Open the app in two browser tabs. Edit the same project in both. Save in Tab A, then save in Tab B → Tab B will get a "Record was changed by another request. Refresh and try again." error instead of silently overwriting Tab A's changes.

Idempotency: Every POST request from the frontend now sends a unique Idempotency-Key header. If a user accidentally double-clicks Submit, only the first request is processed.

Phase 8 — Financial Advisor AI (ML Service) 100%

A standalone Python microservice using FastAPI, scikit-learn, and numpy for AI-powered budget forecasting and risk classification.

How to see this

Run: cd ml-service && pip install -r requirements.txt && uvicorn app.main:app --port 8000
Open: http://localhost:8000/docs for the interactive Swagger API documentation.

Endpoints:
• POST /api/forecast/budget — Input: budget, spent, completion%, months elapsed → Output: projected total cost, overrun %, monthly burn rate, recommendation
• POST /api/risk/classify — Input: completion%, budget utilization, tasks → Output: predicted RAG status (green/amber/red), confidence score, risk factors, recommendation
• Both support /batch for processing multiple projects at once
