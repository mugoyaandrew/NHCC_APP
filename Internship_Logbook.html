Software Engineering Internship Logbook

Project: NHCC Enterprise Application Development

Developer: Andrew Mugoya

Part 1: Developing the Original Base App (Finara Framework)

Initial personal finance tracking interface and frontend architecture

Week 1: Environment Setup & UI Architecture
  • Today I set up the initial React project repository using Vite for fast bundling and development.
  • I configured Tailwind CSS for the project to ensure rapid, responsive UI styling without writing custom CSS files.
  • Today I designed the primary layout shell, including the sidebar navigation and top header components.
  • I implemented the initial routing structure using React Router to navigate between the Dashboard, Income, and Expenses pages.
Week 2: Core Tracking Features
  • Today I built the Income and Expenses components, creating the forms to allow users to input financial records.
  • I implemented state management using React Context to ensure data flows smoothly between the different pages.
  • Today I created the interactive data tables with sorting and filtering capabilities for easy viewing of transaction histories.
  • I wrote logic to calculate total balances dynamically based on the inputted income and expense arrays.
Week 3: Analytics & Goals Module
  • Today I integrated a charting library to visualize spending patterns, rendering dynamic pie charts and bar graphs.
  • I built the Financial Goals tracking module, allowing users to set target amounts and deadlines.
  • Today I wrote mathematical helper functions to calculate the percentage completion of goals based on current savings.
  • I designed the dashboard widgets to display high-level summaries of the user's financial health at a glance.
Week 4: Frontend Polish & Optimization
  • Today I implemented dark mode support across the entire application using Tailwind's dark variant class strategy.
  • I refined the user experience by adding Framer Motion animations to page transitions and modal popups.
  • Today I conducted responsive design testing, ensuring the app looks perfect on both mobile and desktop screens.
  • I finalized the base UI components, preparing the architecture for the enterprise backend integration.

Part 2: NHCC Enterprise Improvements & Backend Integration

Migrating to a robust backend, real-time sync, and AI features

Week 5: Backend API & Prisma Database Migration
  • Today I migrated the application's data layer from client-side storage to a robust SQLite database.
  • I configured Prisma ORM, defining complex data models for Projects, Tasks, Site Reports, and Document management.
  • Today I developed the core Node.js and Express backend API, creating scalable routing for all enterprise CRUD operations.
  • I implemented dynamic API controllers that automatically map incoming JSON data to the correct Prisma models.
Week 6: Security, Authentication & Real-time Comm
  • Today I built a secure authentication system using JSON Web Tokens (JWT) and bcrypt password hashing.
  • I implemented Role-Based Access Control (RBAC) middleware to restrict sensitive routes to authorized personnel only.
  • Today I integrated Socket.io into both the Node server and the React client to enable real-time, bi-directional communication.
  • I wrote logic to instantly invalidate frontend data caches whenever another user modifies a project, ensuring live synchronization.
Week 7: Enterprise Frontend & DevOps Containerization
  • Today I expanded the frontend to include complex enterprise interfaces: Project Portfolios, Task Kanban boards, and Site Reports.
  • I integrated TanStack React Query to efficiently handle data fetching, caching, and background synchronization with the new API.
  • Today I containerized the entire application stack by writing a comprehensive Dockerfile and docker-compose.yml configuration.
  • I set up multi-container networking to ensure the Vite frontend and Node backend communicate securely within the Docker environment.
Week 8: Machine Learning Engine & Audit Logging
  • Today I built a custom Machine Learning integration in the backend to provide predictive budget forecasting.
  • I implemented a heuristic Risk Classification engine that automatically evaluates project parameters to assign Red/Amber/Green statuses.
  • Today I developed the automated Audit Logging system to track every modification made to the database for compliance and accountability.
  • I conducted the final integration tests, optimizing the API response times and finalizing the NHCC Enterprise handover documentation.
